# Contributing

Thanks for helping make nginx safer to operate.

## Ground rules

1. **Do not weaken the safety invariants.** The probe must never create
   memory-unsafe states on the target; ambiguity must surface as INCONCLUSIVE.
2. **Keep it stdlib-only.** The zero-dependency property is a feature for
   a security tool (no supply chain, runs air-gapped). New dependencies
   will be rejected unless there is an overwhelming reason.
3. **Single source of truth.** `src/nginx_h2_probe/` is canonical;
   `nginx-h2-probe.py` is generated by `scripts/build_standalone.py`.
   Never edit the standalone by hand; regenerate it and commit both.
4. **Behavioral changes need lab validation.** Any change to the frame
   sequence, window arithmetic or classification must be validated
   against vulnerable and fixed nginx builds (see the repository's
   validation matrix in the README/CHANGELOG) before merging.
5. `python -m unittest discover -s tests -v` must pass, and CI runs the
   standalone sync check.

## Areas that need help

* Reports (and safe handling) for more vendors: OpenResty, Tengine,
  Angie, Kong, ingress-nginx -- the frame-level test should apply to any
  codebase embedding unpatched nginx h2 code, but this needs validation.
* Smarter flood calibration (fewer attempts on unusual servers).
* A Go single-binary port for scanner hosts without Python.
